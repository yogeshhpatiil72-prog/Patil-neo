PATILNEO — Premium OTT UI Demo

FILES
- index.html: webpage structure
- style.css: responsive purple/black premium design
- script.js: demo title catalogue, search, categories, details modal and My List
- movies.json: optional editable catalogue data reference (the current demo catalogue is inside script.js)

UPDATE EXISTING GITHUB PAGES SITE
1. Extract this ZIP on your phone.
2. Open your GitHub repository.
3. Upload the files inside the patilneo_premium folder to the ROOT of the repository.
4. Choose Commit changes.
5. Wait a few minutes and refresh your GitHub Pages website.

IMPORTANT
- Keep file names exactly as provided.
- Upload the files themselves, not the ZIP.
- This is a static front-end demo. It does not include real film files, user accounts, payments, or a streaming backend.
- To stream videos, use content you own or have permission to distribute. Add licensed video/trailer URLs to the player workflow separately.
